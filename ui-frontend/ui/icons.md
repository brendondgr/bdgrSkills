# Icons System

Icons form a core part of the brand identity. Keep stroke widths consistent and colors functional.

### Functional Mapping
- **Primary Actions**: Brand primary colors.
- **Edit/Manage**: Muted secondary tones.
- **Success/Create**: Bright positive tones.
- **Danger**: High-alert colors.

### Structural Example
```html
<!-- Using generic SVG structure, styled via Utility Classes -->
<svg class="w-6 h-6 text-primary hover:text-white transition-colors" fill="none" viewBox="0 0 24 24" stroke="currentColor">
  <!-- path data -->
</svg>
```
