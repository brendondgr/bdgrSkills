# Buttons & Interactive Elements

Neon glows, responsive interactions, and tactical feedback.

### Feedback Mechanisms
- **Hover States**: Themed neon glows to make dark UI feel alive.
- **Active States**: Slight scaling or press-in effect.

### Structural Example
```html
<!-- Primary Button with Neon Glow -->
<button class="bg-primary hover:shadow-[0_0_15px_var(--primary)] text-black px-6 py-2 rounded-full transition-shadow duration-300">
  Initialize
</button>
```

```html
<!-- Segmented Control Base -->
<div class="flex p-1 bg-surface rounded-lg">
  <button class="flex-1 rounded-md bg-elevated shadow-sm">Option A</button>
</div>
```
