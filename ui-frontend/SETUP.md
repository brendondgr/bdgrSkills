# UI Frontend Setup

When configuring the UI Frontend, please answer the following questions to tailor the frontend skill generation:

1. **Styling Preference:** What CSS framework or styling solution will be used (Tailwind, SCSS, Styled Components, Vanilla CSS)?
2. **Component Library:** Are you planning to implement a specific component library or design system?
3. **Modularity:** How strictly should we isolate components (buttons, modals, motion) into their respective UI modules?
4. **Visual Direction:** What tone should the interface convey (minimal, editorial, utilitarian dashboard, playful, brutalist, luxury, etc.)?

*(AI Note: For full websites, dashboards, and web applications, route layout, page hierarchy, data needs, and frontend/backend boundaries must come from `website-architecture/SETUP.md`. Do not invent structural assumptions from UI preferences alone.)*
